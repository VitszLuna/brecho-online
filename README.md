# Brechó Online — Catálogo & E-commerce

Este repositório contém o código-fonte de uma plataforma web desenvolvida para a divulgação e venda de peças de vestuário seminovas e vintage. O projeto foi projetado para oferecer uma experiência de navegação fluida, permitindo a visualização de produtos, detalhes de peças e facilitando o contato para compras.

🛠️ Tecnologias Utilizadas
React, Java Script, SupaBase

Design & Prototipagem: Figma

Versionamento: Git & GitHub

🚀 Funcionalidades
Catálogo de Produtos: Exibição de peças com fotos, tamanhos e valores.

Filtros e Categorias: Organização por tipo de peça, tamanho ou estilo.

Interface Responsiva: Adaptada para navegação em dispositivos móveis e desktop...
